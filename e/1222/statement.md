This sketch creates a structured visualization of the periodic table as a grid of animated boxes, each pulsing with a luminous glow that travels continuously across the entire structure. The animation uses sine wave functions to create a smooth, ambient oscillation effect where elements appear to pulse and flow with energy. The glow moves from edge to edge in a continuous wave, giving the impression of structured, living energy moving through the table. The technique uses mathematical wave functions to drive color intensity changes across all elements simultaneously, creating a unified visual rhythm without complex particle systems or excessive draw calls.
