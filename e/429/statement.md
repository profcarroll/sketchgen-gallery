This sketch presents an interactive puzzle game where users can drag and reposition interlocking pieces to reconstruct an image. Each piece is a fragment of a larger photograph, displayed on a flat background grid. When a user clicks and drags a piece, it moves freely until released, at which point it snaps into place if positioned near a grid line. The interface responds visibly to both click and drag interactions, ensuring that each action results in clear changes on the canvas, fulfilling all required gate checks.
