This sketch creates a responsive grid of colorful square pads that form a clean, modular structure. Each pad has a randomly assigned color and maintains its position within the grid as the canvas resizes. When a user clicks on any pad, it immediately flashes brightly with white light for 200 milliseconds, providing clear visual feedback while all other pads remain unchanged. The interaction is simple yet effective—clicking any pad triggers a localized flash that confirms the input without disturbing the rest of the grid. This design emphasizes both the structured nature of the grid and the immediate response to user action, creating an engaging yet calm interface.
