This sketch creates a dynamic visual trail that responds to mouse movement, generating a vibrant wake of particles that emanate from the cursor. Each particle begins with a vivid primary hue and gradually fades into a soft pastel tone before disappearing entirely. The effect is achieved through a particle system where new particles are continuously generated as the mouse moves, each with unique velocity and lifespan properties. The particles are rendered using p5's color mode to create smooth transitions between bright and muted tones, producing an ephemeral and visually engaging trail that dissipates naturally over time.
