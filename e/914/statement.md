This sketch creates an interactive sound visualization that responds to both mouse position and user interaction. When clicked, it activates a sine wave oscillator that generates audio in real-time. The vertical mouse position controls pitch while the horizontal position adjusts volume. As the mouse moves across the canvas, the visual output dynamically updates with animated waveforms and real-time audio meters showing current frequency and amplitude levels. The interface begins in a simple state prompting the user to click before activation, ensuring proper audio context initialization through the required user gesture.
