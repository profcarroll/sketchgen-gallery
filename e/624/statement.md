This sketch generates an abstract, evolving visual composition centered on a core point from which thousands of dynamic lines radiate outward. Each line moves in a spiral pattern, constantly shifting its angle and radius to create complex interlocking formations. The continuous motion builds visual energy that resembles sound waves made visible, with color and density varying across the field. The system uses WEBGL rendering for smooth, flowing motion without any user interaction, creating an immersive, non-repeating pattern that fills the canvas with perpetual motion.
