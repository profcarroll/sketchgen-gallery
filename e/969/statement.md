This sketch creates a visually accurate piano keyboard that responds to user interaction with both sound and visual feedback. The interface displays 52 keys arranged in the familiar white and black pattern of a piano, with proper spacing and sizing. When a key is pressed, it immediately produces a musical tone using Web Audio API's oscillator and simultaneously depresses visually to simulate physical interaction. The visual effect uses subtle color changes and shape modifications to indicate key press without overcomplicating the design. The implementation respects performance constraints by avoiding expensive operations in the draw loop and managing audio context properly through user gestures, ensuring both visual and auditory responses are clearly perceivable while maintaining smooth frame rates.
