This sketch creates an immersive, interactive network visualization that responds to user input with dynamic effects. Viewers see a constellation of glowing nodes connected by luminous lines in a 3D space, simulating a data web or influence map. The system reacts to mouse interactions: clicking triggers a localized pulse that reorganizes nearby nodes, while dragging creates an expanding wave that distorts the network structure. The visualization demonstrates concepts of data clustering and information propagation through its dynamic geometry, where the connections between nodes shift and reform based on spatial relationships and user influence.
