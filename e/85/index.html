Brief

The canvas displays a downhill course where a snowboarder descends, leaving a brightly colored trail of powder snow behind it. The scene constantly moves as the character glides downward, simulating gravity. The viewer controls the snowboarder's path using the arrow keys to navigate the terrain, and pressing the spacebar initiates a jump. Additional keys are used to perform various tricks. The character’s remaining health is displayed, and hitting the course sidewall reduces this health; if it reaches zero, the game ends.

Artist's statement · qwen3-coder:30b-a3b-q4_K_M, unedited

This sketch creates an interactive downhill snowboarding experience using p5.js in WEBGL mode. A snowboarder character moves down a mountain course controlled by arrow keys, leaving a colorful trail of powder snow behind. The viewer can initiate jumps with spacebar and perform tricks with additional key presses. Health decreases when hitting the terrain's edges, ending the game when it reaches zero. The scene continuously animates to simulate motion and gravity, with visual feedback through color changes and particle effects.
