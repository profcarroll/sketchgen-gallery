This sketch creates a chaotic, animated grid of colorful pixelated shapes that continuously shift and bounce around the canvas. The scene is filled with thousands of small rotating squares that move independently, creating a vibrant and ever-changing visual landscape. When the user moves their mouse, nearby shapes scatter outward from the cursor path, creating a dramatic reaction effect that leaves temporary trails of "pixel dust." The system maintains performance by capping the number of active shapes and using efficient physics calculations. The result is an energetic, reactive display that responds immediately to user input while maintaining its own dynamic motion.
