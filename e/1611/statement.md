This sketch presents a minimalist vertical skyline that responds to keyboard input. Initially populated with a few rectangular floors, the structure remains static until a key is pressed. Each keystroke triggers the addition of a new floor at the topmost point, creating an expanding vertical composition. Each new floor inherits a distinct color generated through a mathematical hue sequence, ensuring visual variety without repetition. The interaction is deliberate and immediate: pressing any key causes the skyline to grow, demonstrating how simple rules can generate evolving complexity from static beginnings. The design emphasizes clean geometry and systematic color progression, creating a visual rhythm that emerges from user engagement rather than animation or motion.
