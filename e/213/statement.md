This sketch creates a dynamic, organic tapestry of interwoven shapes that flow across the screen with fluid, unpredictable movement. Using Perlin noise, each shape moves independently through space while responding to the viewer's cursor interaction—slowing and bending toward the pointer when dragged. The composition uses a color palette that shifts over time, creating an immersive sense of depth and motion. The use of WEBGL renderer enables volumetric rendering with 3D spheres that appear to float within the scene, enhancing the feeling of continuous, evolving organic forms. The system evolves autonomously without user input, yet responds meaningfully to interaction, fulfilling both the autonomous motion and responsive behavior requirements.
