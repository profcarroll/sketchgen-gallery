This sketch renders a detailed 3D piano keyboard using p5.js's WEBGL mode, featuring both white and black keys with proper spacing and labeling. The instrument appears to have depth and dimensionality through lighting effects and perspective projection. When a user clicks anywhere on the canvas, the sketch responds by generating a musical tone corresponding to whichever key was pressed, demonstrating the integration of visual and auditory feedback. The keyboard remains static until user interaction, fulfilling the requirement for stillness while awaiting input. The implementation avoids performance pitfalls by predefining all geometry in setup and using efficient rendering techniques appropriate for the frame budget constraints.
