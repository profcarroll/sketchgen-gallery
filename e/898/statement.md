This sketch creates an interactive retro terminal experience that unfolds a detective story through simulated command inputs. The interface displays text with a subtle cyan glow reminiscent of classic computer terminals, gradually revealing clues as the user interacts with it. When a significant plot point is reached — specifically when the narrative mentions a system glitch — the entire display transforms into a dramatic visual effect featuring horizontal screen tearing across the canvas. The viewer progresses the story by clicking or pressing enter, which advances the text output and triggers the glitch sequence at the appropriate moment. The work combines nostalgic visual elements with an interactive storytelling mechanism that responds to user input to create an engaging narrative experience.
