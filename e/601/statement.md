This sketch creates a continuously evolving abstract composition using thick diagonal stripes that shift and warp over time. The stripes move rhythmically across the canvas, their angles and widths changing in response to sine wave functions that create organic, flowing motion. Each stripe is overlaid with a repeating halftone dot pattern, giving the bold geometric shapes a structured, printed appearance. The composition changes entirely on its own without any user interaction, creating a dynamic, non-repeating abstraction that fills the entire canvas with shifting visual rhythm.
