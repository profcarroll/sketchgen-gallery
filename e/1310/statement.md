This sketch creates a mesmerizing display of nested circular forms composed of segmented rectangular blocks that pulse and undulate in rhythmic harmony. Each ring is constructed from discrete rectangular segments that oscillate in phase with one another, creating a visual effect reminiscent of harmonic sine waves propagating through space. The color palette draws from deep purples, magenta hues, and varying shades of blue to create a cohesive yet dynamic visual field. The animation proceeds automatically without any user interaction, with each ring's segments expanding and contracting in a predictable, cyclical pattern that maintains continuous motion across the entire canvas. The technique uses trigonometric functions to control both the positioning and timing of the segment oscillations, creating a consistent, hypnotic rhythm that fills the screen with flowing, wave-like motion.
