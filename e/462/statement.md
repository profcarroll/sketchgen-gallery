This sketch creates a dynamic grid of interconnected squares that gently pulse with a breathing rhythm against a dark background. The system uses a cellular grid where each square has its own oscillating pulse that varies in intensity over time. When the user clicks anywhere on the canvas, an outward-moving ripple effect emanates from the click point, temporarily altering the base color of affected squares and creating a visual wave that travels across the entire grid. The effect is achieved through careful timing and distance calculations, where each square's brightness is modulated based on its proximity to the ripple center, producing a smooth, organic-looking animation that responds both to continuous motion and discrete user interaction.
