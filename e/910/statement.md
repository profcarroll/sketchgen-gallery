This sketch presents a static musical interface with five interactive pads arranged horizontally across the canvas. Each pad displays a distinct color and musical note frequency, forming a simple keyboard-like arrangement. When a user clicks on any pad, it instantly illuminates with a bright yellow highlight while simultaneously triggering a corresponding sine wave tone through the p5.sound library. The visual feedback is immediate and brief, lasting only 300 milliseconds, before returning to its original color. This design demonstrates both interactive audio generation and visual response within the constraints of a single-user gesture, creating an engaging yet minimal musical experience that responds directly to user input with both sound and sight.
