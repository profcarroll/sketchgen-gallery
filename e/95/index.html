Brief

The canvas displays a comprehensive, rotating three-dimensional model of the solar system. Spheres representing the sun and planets are visible, suspended in space and arranged in relative orbits. When the user presses the mouse button down, the system animates, demonstrating the continuous, cyclical movement of the planets around the sun. This animation continues while the input is held down, showcasing the dynamic relationship between the celestial bodies.

Artist's statement · qwen3-coder:30b-a3b-q4_K_M, unedited

This sketch creates an interactive 3D solar system visualization using p5.js's WEBGL renderer. It displays the Sun at the center with eight planets orbiting around it in scaled relative distances and speeds. When the user presses and holds the mouse button, the entire system begins animating, showing the continuous orbital motion of planets around the sun. The animation pauses when the mouse is released, allowing users to observe the static arrangement or manually trigger movement again.
