This sketch creates a living grid of interconnected squares that breathe with a gentle, synchronized pulsation. Each square pulses in unison with others across the canvas, creating an organic rhythm. When clicked, a wave radiates outward from the point of contact, disturbing the natural flow and leaving behind a colored shadow that gradually fades back to the original pulse. The effect is both mesmerizing and responsive — viewers can interact with the grid to create ripples that travel through the field, watching as each square returns to its base state over time. The technique uses a grid-based system where each cell maintains its own state and responds to both its inherent pulsation and external disturbances.
