This sketch creates a dynamic honeycomb pattern that evokes the visual effect of a beehive observed through a thermal camera. The hexagonal cells pulse gently with shifting warm colors—deep reds and oranges transitioning into cooler blues—representing varying temperatures. A prominent diagonal channel cuts across the pattern, glowing with intensified color gradients that pulse rhythmically, suggesting heightened thermal activity along that path. The entire composition moves slowly and continuously without any user interaction, using only the core p5.js library to generate an immersive, animated thermal landscape.
