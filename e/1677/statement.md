This sketch creates an abstract quilt surface composed of geometric patches arranged in a regular grid pattern that flows with a continuous wave motion. Each patch follows its own unique wave path while maintaining its individual shape and color transitions. The patches move smoothly across the canvas in a synchronized but varied rhythm, creating an organic ripple effect across the entire surface. The color palette shifts gradually through a day-cycle transition, with each patch slowly morphing between hues to create a sense of temporal flow. The motion appears natural and continuous without any user input, driven purely by mathematical wave functions that govern both position and size variations.
