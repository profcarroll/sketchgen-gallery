This sketch renders a dynamic, three-dimensional cityscape using p5.js's WEBGL renderer. The scene features a grid of randomly placed buildings of varying heights and colors, set against a shifting sky that changes with the passage of simulated time. As the sun moves across the sky, casting light and creating shadows that stretch and shift across the city, the entire environment breathes with an artificial day-night cycle. The visual effect is achieved through geometric building blocks, dynamic lighting, and carefully placed shadows that respond to the sun's position, all rendered in real-time without any user interaction.
