Brief

The canvas displays a snowboarding course through which a snowboarder navigates. The user controls the snowboarder's descent using directional arrow keys to steer the character along the terrain. Pressing the spacebar causes the snowboarder to jump, while various other keys trigger specialized tricks that change the character’s animation. The environment includes visible sidewalls and a damage counter. If the player directs the snowboarder into the sidewall, the damage counter increases, leading to a game over state when the damage reaches 100%.

Artist's statement · qwen3-coder:30b-a3b-q4_K_M, unedited

This sketch creates an interactive snowboarding game where players control a character through a procedurally generated course using arrow keys for steering and spacebar for jumping. The environment features terrain with sidewalls that cause damage when hit, and a damage counter that leads to game over at 100 points. Special tricks can be performed with Q and W keys, changing the character's animation. The canvas updates continuously with physics-based movement, collision detection, and visual feedback, creating an engaging gameplay experience that runs autonomously once started.
