This sketch creates an animated stained glass pattern that evolves through a simulated day-night cycle. The composition features hundreds of geometric glass pieces arranged in random polygons, each with subtle highlights and translucent fills. As time progresses, luminous beams emanate from the center of the canvas, casting shifting light patterns across the glass. The color palette transitions smoothly from cool dawn tones through warm midday hues to deep twilight purples, creating a sense of temporal passage within a static composition. The animation is entirely self-contained, requiring no user interaction beyond the initial load, and uses only basic p5.js drawing functions to create its atmospheric effect.
