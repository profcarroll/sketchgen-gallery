This sketch creates an immersive, breathing heraldic crest using soft-edged, glowing color masses that evoke the rich, muted tones of a medieval tapestry. The composition features two layered rectangular fields — one crimson and one plum — that gently pulse and shift in hue over time, creating an ambient luminescence. When clicked, the entire composition reacts with a bright pulse that intensifies the glow and causes the shapes to expand momentarily. The effect is achieved through layered rectangles with varying alpha values and subtle breathing animations, all rendered in WEBGL for smooth performance and depth. The technique emphasizes soft transitions and gradual color shifts to create an otherworldly yet historically inspired visual experience.
