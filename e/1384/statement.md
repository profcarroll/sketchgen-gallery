This sketch creates a serene, animated field of rhododendron blooms that gently float and pulse with life. Using organic shapes and layered ellipses, each bloom features a central core surrounded by leafy foliage. The blooms drift slowly across the canvas with subtle spring-like motion, responding to mouse interactions by scattering briefly under the cursor's touch before reforming into new patterns. The visual effect combines smooth animation with responsive interaction, creating an immersive environment that feels both static and alive.
