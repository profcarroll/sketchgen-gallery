This sketch renders a three-dimensional animated DNA double helix using p5.js's WEBGL renderer. The structure consists of labeled spheres representing nitrogenous bases (A, T, C, G) arranged in a helical pattern with complementary base pairing logic. As the helix rotates, bases from opposite strands approach each other and temporarily form hydrogen bonds when properly aligned. These dynamic bonds are visualized as connecting lines that fade out over time, simulating molecular interactions. The animation runs continuously without user input, demonstrating how genetic information is encoded through base-pairing rules in a visually engaging way.
