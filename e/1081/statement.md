This sketch creates a visual representation of a guitar fretboard that responds to user interaction with both visual and auditory feedback. When a viewer drags their cursor across the strings, the sketch produces musical notes corresponding to different fret positions on the guitar. The visualization shows distinct strings stretched across visible frets, with a dynamic effect illustrating string vibration as the mouse moves. The audio response is generated through p5's sound library, with each string-fret combination producing a unique note based on standard tuning. The work demonstrates how visual elements can be mapped to musical parameters in real-time, creating an interactive musical instrument visualization that responds to both touch and motion.
