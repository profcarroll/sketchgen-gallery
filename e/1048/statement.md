This sketch simulates a radar-like detection system sweeping across a dark grid field. Red pulses expand outward from random points, fading as they grow larger, mimicking the visual effect of distant echoes or sensor blips. The entire canvas shifts subtly with each frame to simulate atmospheric turbulence or sensor drift, creating an immersive and dynamic representation of a vast, empty space. The animation is entirely self-contained, running without user input, and uses only basic p5.js functions within strict performance constraints.
