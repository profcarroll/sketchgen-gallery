This sketch creates a retro terminal interface with an amber glow effect that simulates a mysterious detective investigation system. The program automatically generates a sequence of system messages and commands that unfold the story of a missing persons case, displaying them in real-time on screen. Periodically, the system output is disrupted by visual glitches—random character substitutions—that mimic hardware malfunctions or data corruption during intense processing. The viewer observes an evolving narrative through terminal-style text output, with the occasional visual disruption adding tension and atmosphere to the detective story being told.
