This sketch creates a layered drawing experience where users can trace paths across the canvas. The interface records continuous strokes that maintain consistent parallel alignment regardless of input motion, building up a dense, overlapping tapestry of graphite-like marks. Each new pass adds color intensity through layering and overlapping, producing a rich visual texture. The implementation uses p5.js's drawing primitives to create smooth, continuous lines while maintaining performance within the strict frame budget constraints, ensuring that even extensive drawing sessions remain responsive and visually coherent.
